# Commercial Operating Backlog

This is the execution layer for the AI/API commercial operation.

## Priority 0 — Revenue now

1. Hunt fresh paid opportunities every day across legitimate sources.
2. Prioritize problems we can solve with the Category A arsenal in days, not weeks.
3. Prefer direct-contact prospects, clear business pain, and small paid pilots.
4. Track contacted prospects and never send duplicate cold outreach.
5. Follow up on unanswered qualified prospects at a reasonable cadence.
6. Record replies, objections, requested scope, price signals, and next action.

## Priority 1 — Reusable delivery assets

Build provider-neutral templates for:
- REST API integration
- OAuth/webhook integration
- n8n workflow repair
- AI lead qualification
- AI email classification
- CRM synchronization
- WhatsApp/SMS/voice automation
- document extraction/OCR pipelines
- Shopify automation
- customer-support agents
- reporting/data dashboards
- automation audits

Each asset should be reusable across multiple clients and keep credentials outside the repository.

## Priority 2 — Commercial packaging

Maintain three entry offers:

### Quick Fix
A narrowly scoped automation/API repair delivered quickly.

### Paid Pilot
A measurable workflow or integration delivered as a proof of value.

### Retainer
Monitoring, maintenance, optimization, and additional automations after the pilot succeeds.

## Priority 3 — Arsenal expansion

When a new skill/plugin/API appears, evaluate it against:
1. revenue potential
2. implementation speed
3. source credibility
4. security/permissions
5. maintainability
6. compatibility with Codex/ChatGPT

Install or vendor only when there is a concrete commercial reason. Do not collect tools for collection's sake.

## Priority 4 — Security

Never commit API keys, tokens, passwords, OAuth secrets, customer credentials, or private customer data. Use environment variables, GitHub Actions Secrets, Replit Secrets, or a production secret manager.

## Operating principle

**Lead → qualify → small paid outcome → deliver fast → prove value → expand → maintain.**

The objective is not to build a large toolbox. The objective is to turn the toolbox into paid outcomes repeatedly.
