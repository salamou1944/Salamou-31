# AI / Codex / ChatGPT Skills Catalog

This file records the skills we selected for the commercial AI/API workspace.

## Policy

We do not blindly copy every GitHub skill. Skills are reviewed for relevance, license, dependencies, permissions, and security before being adopted. Real API keys, tokens, passwords, OAuth secrets, and credentials must never be committed.

## Source

The OpenAI repository currently states that it is deprecated and directs users to the OpenAI Plugins repository for current Codex skill/plugin examples. Therefore this catalog prioritizes current official material and treats third-party catalogs as candidates, not automatically trusted code.
