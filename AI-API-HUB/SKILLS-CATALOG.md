## Adoption policy

We do not blindly copy every GitHub skill. Skills are reviewed for relevance, provenance, license, permissions, network/API behavior, scripts, dependencies, secret handling, maintenance, and compatibility before adoption.

Real API keys, tokens, passwords, OAuth secrets, and credentials must never be committed.

**Important:** Category A is an approved arsenal/priority set. It does not mean every upstream skill has already been physically vendored into this repository. Actual installations should use official installers/plugins or individually reviewed local copies.
