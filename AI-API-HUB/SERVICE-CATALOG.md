## Delivery model
1. Discovery / problem definition
2. Small paid pilot
3. Production implementation
4. Monitoring and maintenance

## Commercial principle
Do not sell "an API" when the buyer actually needs a business result. Sell the result and use the appropriate APIs/tools behind it.

## Security
Never commit real credentials. Use environment variables, GitHub Actions Secrets, Replit Secrets, or a production secret manager.
